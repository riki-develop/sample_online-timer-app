# 概要
  
Online Timer App プロトタイプ  
  
## ◻︎開発環境
```
- vite/7.2.4
  - Node.js v20.19以上を推奨
  - pnpm v10以上を推奨
```
  
※昨今の **npmパッケージの脆弱性問題** を踏まえ、パッケージマネージャーは **pnpm** を採用
### ▼pnpmのインストール方法
```
## Homebrewを使用する想定
brew install pnpm

## 公開から2週間以上経過したパッケージのみをインストールする
pnpm config set --location=global minimumReleaseAge 20160

## 設定を確認
pnpm config list --location=global
```
### ▼開発手順
1. このリポジトリをcloneする  
2. `pnpm install` で依存関係をインストール  
3. `pnpm dev` で開発サーバーを起動->`http://localhost:3000` を開く  
4. coding  
5. `pnpm build` でビルド->完成したLPが`dist/`に出力される  
  
## ◻︎要件定義
- ユーザーがOnlineTimerを分単位で設定（min 1, max 60 ※仮）できる
  - 初期画面では時間設定バー（スワイプ操作可）とスタートボタン、終了時の音を出すor出さないの切り替えボタンを表示
- スタートボタンを押すとカウントダウンが開始され、残り時間が秒単位で表示される
  - カウントダウン中は一時停止ボタンとリセットボタンを表示
  - 一時停止ボタンを押すとカウントダウンが一時停止し、再度押すと再開
  - リセットボタンを押すとカウントダウンが初期状態に戻る
- カウントダウンが終了すると、設定に応じて音が鳴る（例: アラーム音）
  - 音を出す設定の場合は、カウントダウン終了時にアラーム音が鳴る
  - 音の設定に関係なく、カウントダウン終了時に画面上で通知（例: 「時間です！」のメッセージ）を表示
